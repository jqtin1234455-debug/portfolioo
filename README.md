# Portfolio Website

A complete, professional, premium, and fully responsive portfolio website available as **React**, **Next.js**, and **Vue.js** editions, featuring routed page views, interactive tools, and a clean, contact-light presentation.

---

## 🌟 Live Local Servers

| Framework | Local URL | Port | Features |
|---|---|---|---|
| **▲ Next.js Edition** | `http://localhost:3000/` | 3000 | Next.js App Router, React 19, Tailwind CSS v4, Lucide Icons |
| **⚛️ React 19 Edition** | `http://localhost:5173/` | 5173 | React Router v7, Tailwind CSS v4, Lucide Icons, Canvas Confetti |
| **💚 Vue 3 Edition** | `http://localhost:5174/` | 5174 | Vue Router 4, Composition API, Tailwind CSS v4, Lucide Icons |

The React and Vue apps feature a one-click **Framework Switcher**. The Next.js edition uses the same React portfolio pages with file-based App Router routes.

## 💻 How to Run the Projects

### Running React Edition (Port 5173)
```bash
cd react-app
npm run dev
```

### Running Next.js Edition (Port 3000)
```bash
cd next-app
npm install
npm run dev
```

### Running Vue.js Edition (Port 5174)
```bash
cd vue-app
npm run dev
```

### Production Build
```bash
# In react-app
npm run build

# In next-app
npm run build

# In vue-app
npm run build
```
